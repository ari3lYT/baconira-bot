# Baconira Bot

Бот для тикетов, анкет гражданства, предложений и личных голосовых комнат. Укажи `DISCORD_GUILD_ID`,
установи зависимости и запусти `python bot.py`. Токен вводится скрыто. Команда `/настроить` создаёт
и настраивает структуру сервера; сначала проверь нужные роли и права на тестовом сервере.

Архивирование тикета сохраняет сообщения и вложения в HTML. При ошибке канал остаётся на месте.
Каталог `data/`, токен и реальные архивы никогда не должны попадать в публичный репозиторий.
