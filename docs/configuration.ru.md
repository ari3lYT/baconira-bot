# Настройка

| Параметр | Назначение |
| --- | --- |
| `DISCORD_GUILD_ID` | Обязательный числовой ID единственного сервера, где разрешена настройка |
| `DISCORD_BOT_TOKEN` | Необязательный токен из окружения; иначе ввод или чтение `.token` |
| `BACONIRA_DATA` | Каталог постоянного состояния; по умолчанию `data/` рядом с кодом |
| `avatar.png` | Необязательная иконка сообщества |
| `bot-avatar.png` | Необязательная иконка бота; при отсутствии используется `avatar.png` |
| `welcome-banner.png` | Необязательное приветственное изображение |

Нужны права View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Manage Channels, Manage Roles, Move Members, Connect, Manage Threads и Send Messages in Threads. Проверьте план прав для своего сервера. Глобальный Administrator не требуется. Включите Server Members и Message Content intents. Предложения в нативных форумах требуют сервера с включённым Community.

Команда администратора может менять переопределения прав каналов и создавать роли и категории. Сначала проверьте выбранную структуру на отдельном тестовом сервере. Настройка повторно использует ресурсы с существующими именами; неоднозначные дубликаты отклоняются. Не удаляйте каталог состояния при обновлении: он содержит активные дела и данные восстановления архивов.
